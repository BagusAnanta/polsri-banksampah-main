# 🚀 Laravel Deployment ke Ubuntu VPS (Tanpa Docker)

## 1. Persiapan VPS

Update package

```bash
sudo apt update
sudo apt upgrade -y
```

Install software yang dibutuhkan

```bash
sudo apt install nginx git unzip curl software-properties-common -y
```

---

## 2. Install PHP

Tambahkan repository PHP

```bash
sudo add-apt-repository ppa:ondrej/php
sudo apt update
```

Install PHP

```bash
sudo apt install php8.3 php8.3-fpm php8.3-cli php8.3-common
```

Install extension Laravel

```bash
sudo apt install \
php8.3-mysql \
php8.3-mbstring \
php8.3-xml \
php8.3-curl \
php8.3-zip \
php8.3-gd \
php8.3-bcmath \
php8.3-intl
```

---

## 🟡 Error yang terjadi

### Error

```
could not find driver
```

### Penyebab

Extension MySQL belum terinstall.

### Solusi

```bash
sudo apt install php8.3-mysql
sudo systemctl restart php8.3-fpm
```

---

# 3. Install Composer

```bash
sudo apt install composer
```

Cek

```bash
composer --version
```

---

# 4. Install MySQL

```bash
sudo apt install mysql-server
```

Login

```bash
sudo mysql
```

Buat database

```sql
CREATE DATABASE banksampah;
```

Buat user

```sql
CREATE USER 'banksampah'@'localhost' IDENTIFIED BY 'password';
```

Grant

```sql
GRANT ALL PRIVILEGES ON banksampah.* TO 'banksampah'@'localhost';
FLUSH PRIVILEGES;
```

---

## 🟡 Error

```
Access denied for user
```

### Penyebab

User belum memiliki permission.

### Solusi

Grant privilege lagi.

# 9. Nginx

Buat config

```
/etc/nginx/sites-available/banksampah
```

Isi

```nginx
server {

    listen 80;

    server_name staging.example.com;

    root /var/www/banksampah-staging/public;

    index index.php;

    location / {

        try_files $uri $uri/ /index.php?$query_string;

    }

    location ~ \.php$ {

        include snippets/fastcgi-php.conf;

        fastcgi_pass unix:/run/php/php8.3-fpm.sock;

    }

}
```

Enable

```bash
sudo ln -s
```

Test

```bash
sudo nginx -t
```

Reload

```bash
sudo systemctl reload nginx
```

# 11. Route Register 404

Login bisa

```
/login
```

Register

```
404
```

Padahal route ada.

---

## 🟡 Penyebab

Di

```
AppServiceProvider.php
```

ada

```php
URL::forceScheme('https');
```

Karena

```
APP_ENV=staging
```

Maka Laravel selalu membuat URL HTTPS.

Padahal server belum pakai SSL.

---

### Solusi

Sebelumnya

```php
if (!app()->environment('local'))
```

Diganti

```php
if(app()->environment('production'))
```

Lebih bagus lagi

```
FORCE_HTTPS=true
```

di `.env`.

# 13. Upload Gambar Gagal

Error

```
Unable to write

public/ui/images/masyarakat
```

---

## Penyebab

Owner folder

```
root
```

PHP jalan sebagai

```
www-data
```

Tidak punya permission.

---

## Solusi

```bash
sudo chown -R www-data:www-data public/ui/images
```

```bash
sudo chmod -R 775 public/ui/images
```

---

# 14. Error Baru

Setelah upload selesai

Muncul

```
storage/logs/laravel.log

Permission denied
```

---

## Penyebab

Storage masih dimiliki

```
root
```

---

## Solusi

```bash
sudo chown -R www-data:www-data storage
```

```bash
sudo chmod -R 775 storage
```

---

Dan juga

```bash
sudo chown -R www-data:www-data bootstrap/cache
```

```bash
sudo chmod -R 775 bootstrap/cache
```

# 15. Cek PHP-FPM User

Kalau bingung PHP jalan sebagai siapa

```bash
ps aux | grep php-fpm
```

Hasil

```
www-data
```

Berarti semua folder yang ditulis Laravel harus writable oleh

```
www-data
```

# 📌 Pelajaran yang Paling Berharga Hari Ini

Kalau ada error, **jangan langsung panik**. Coba identifikasi dulu error itu berasal dari lapisan mana.

```
Browser
    │
    ▼
DNS
    │
    ▼
Nginx
    │
    ▼
PHP-FPM
    │
    ▼
Laravel
    │
    ▼
Database
```

Contohnya:

* **404** → cek Nginx atau Route.
* **500 Internal Server Error** → cek `storage/logs/laravel.log`.
* **Permission denied** → cek `chown`, `chmod`, dan user `www-data`.
* **Access denied** → cek konfigurasi MySQL.
* **could not find driver** → cek extension PHP.
* **Login bisa tapi URL aneh** → cek `APP_URL` dan `URL::forceScheme()`.
